# Мои цели на семестр

1. Настроить полноценный CI/CD пайплайн (GitHub Actions) для пет-проекта: линтинг, тесты, автодеплой.
2. Научиться уверенно работать с Docker: писать Dockerfile, использовать docker-compose для локальной разработки.
3. Освоить основы Linux-администрирования (systemd, базовая настройка сети, работа с правами доступа) достаточно, чтобы самостоятельно развернуть и поддерживать сервис на VPS.
