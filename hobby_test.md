# Мой пет-проект (тестовый повтор задания для скриншотов)

Идея: телеграм-бот для учёта личных расходов (запись трат по категориям, месячная сводка).

Стек: Python (aiogram) + PostgreSQL, задеплоенный в Docker-контейнере.

Цель: научиться писать Dockerfile и docker-compose для многосервисного приложения, а затем настроить автодеплой через GitHub Actions при пуше в main.
