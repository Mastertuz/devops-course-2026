# Git: VS Code vs терминал

Удобное в VS Code:
1. Наглядный diff файла (изменённые строки подсвечены прямо в редакторе, не нужно вручную запускать `git diff`).
2. Коммит через UI одним кликом: ввёл сообщение, нажал ✓ — не нужно помнить флаги `git commit -m`.
3. GitLens показывает, кто и когда изменил каждую строку (git blame), прямо во всплывающей подсказке при наведении.

Удобнее в терминале:
- Сложные операции вроде `git rebase -i`, `git cherry-pick` или разбор запутанных конфликтов при merge — в терминале виден точный вывод каждой команды и проще понять, что реально произошло, тогда как UI скрывает часть деталей.
